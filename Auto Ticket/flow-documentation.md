# Flow Designer Documentation

## Flow Name
Auto Ticket Classification

## Trigger
When a new ticket/incident is created.

## Flow Steps
1. Trigger: Record created.
2. Get the ticket details.
3. Check the ticket description/category.
4. Use conditions to identify the ticket type.
5. Update the ticket category and priority.
6. Save/update the record.

## Sample Conditions

| Ticket Information | Classification |
|---|---|
| Email access issue | Email |
| Password/login issue | Authentication |
| Hardware issue | Hardware |
| Network connection issue | Network |
| Software/application issue | Software |
