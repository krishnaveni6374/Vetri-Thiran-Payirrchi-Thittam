# Project Documentation

## Title
Auto Ticket Classification using Flow Designer

## Objective
Automatically classify incoming support tickets using a ServiceNow Flow Designer workflow.

## Expected Result
The system identifies the type of ticket and updates the relevant classification fields automatically, reducing manual work.

## Testing
Create test tickets with different descriptions and verify that the flow assigns the expected classification.
